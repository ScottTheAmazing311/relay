# Relay Workplace Logistics

Brand and website for Relay, a commercial office moving and logistics company:
furniture decommission, transport, storage, and reassembly. Out Friday. Open Monday.

## Structure

- `index.html` — the site (static, no build step; fonts from Google Fonts)
- `img/` — photography (demo imagery; replace with licensed photos before launch)
- `brand/` — brand book and logo SVGs

## Deploy (Vercel)

Import this repo at https://vercel.com/new — framework preset "Other", no build
command, output directory left blank. Vercel serves `index.html` at the root.
Every push to `main` deploys automatically.

## Placeholders to replace before launch

Phone, email, and USDOT number in the page are placeholders, and the quote form
shows a demo notice on submit (wire it to a real inbox or form service).
